# ILLIST - Official Band Website

A portfolio and merch website for **ILLIST**, a metalcore/nu-metal band rooted in Virginia.

## About the Band

Illist is a metalcore/nu-metal band that has spent months shaping their unique sound. An early article from The Metal Resource noted the band's dedication to their craft.

### Band Members
- **Micah Elias** - Lead Vocalist (Band Leader)
- **Jerod Folk** - Guitar
- **Taylor Youstra** - Bass
- **Cecil Johnson** - Drums

## Website Features

This website includes:
- **Hero Section** - Eye-catching landing page with glitch effect logo
- **About Section** - Band biography and history
- **Band Members** - Detailed profiles of all band members
- **Music Section** - Links to streaming platforms (Spotify, Apple Music, YouTube, Bandcamp)
- **Merch Store** - Official merchandise including t-shirts, hoodies, beanies, vinyl, patches, and posters
- **Contact Section** - Social media integration and newsletter signup
- **Responsive Design** - Mobile-friendly and works on all devices
- **Dark Theme** - Metalcore aesthetic with red accents

## Technologies Used

- HTML5
- CSS3 (with custom animations and responsive design)
- Vanilla JavaScript
- Google Fonts (Bebas Neue, Roboto)

## Local Development

To run this website locally:

1. Clone the repository
2. Open `index.html` in your browser, or
3. Start a local server:
   ```bash
   python3 -m http.server 8000
   ```
4. Navigate to `http://localhost:8000`

## Design Philosophy

The website features a dark, aggressive aesthetic that matches the band's metalcore/nu-metal sound:
- Dark background (#0a0a0a, #050505)
- Bold red accents (#ff0000)
- Modern typography with Bebas Neue for headers
- Glitch effects and animations
- Smooth scrolling and interactive elements
